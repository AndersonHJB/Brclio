# Bornforthis 角色参考图分析

## 输入参考图

- `design-options/02-headphone-earcup.png`
- `fullbody-options/16-personal-brand-hero.png`

第一张负责面部身份与近景蜡笔笔触；第二张负责成年全身比例、动作、贴纸边和整体完成度。参考图中的黄色背景不继承到文章配图；耳机、蓝夹克、相机、相机包和笔记本也不继承为固定设定。

## 固定外形提炼

- 年轻成年男性，亲和、镇定、清爽，不幼儿化。
- 紧凑方圆脸，面部保持纸张白色，不铺写实肤色。
- 短而上扬的碎发，顶部有清楚的尖翘轮廓；以品牌蓝蜡笔排线表现。
- 平直蓝眉，简化蓝眼，不画巨大高光眼。
- 小而清楚的黄色点状鼻子。
- 左右脸颊各一枚圆形黄色腮红。
- 轻微闭口微笑，温暖、自信、专注。
- 耳朵简化但可见。
- 人物约 4.5–5 头身，成年比例轻度卡通化。
- 人物外缘有不规则白色剪纸/贴纸留边。

## 一词识别点

**黄腮红**

它是两张参考图都稳定存在、且不依赖服装与配饰的面部特征。遮住衣服、耳机和道具后，黄腮红仍能与蓝碎发、白脸共同完成识别。

辅助识别链：**蓝碎发 + 白脸 + 黄腮红**。

## 画风关键词

`纯白背景`、`手绘蜡笔`、`彩铅排线`、`纸面颗粒`、`断续笔触`、`压力不均`、`不规则白色贴纸边`、`2D 平面`、`大留白`、`轻微不对称`、`可爱但有品质`、`温暖`、`非 AI 光滑感`、`低科技手作隐喻`。

## 品牌色与参考图关系

参考图主要展示蓝黄关系，并带少量红色点缀。它证明三个品牌色是角色的识别基础，但没有证明“场景只能使用这三种颜色”。v3 因此采用两层色彩逻辑：

- 身份与品牌结构继续由 `#2B7FD8`、`#F4D758`、`#E84A5F` 控制。
- 内容物件可以使用真实或语义合理的绿色、青色、紫色、棕色、灰色、橙色等。
- 新颜色必须服从手绘蜡笔质感，不能变成霓虹色、摄影色或第二套抢眼品牌色。

## 可变项

- 耳机：音频、专注、降噪或音乐主题才使用；可以戴耳朵、挂脖或不出现。
- 蓝色夹克：只是参考图中的一种穿搭。
- 相机与相机包：摄影、记录、采集主题道具。
- 笔记本：写作、研究、学习主题道具。
- 鞋、裤子、内搭、外套：按场景变化。
- 其它配饰：可按主题添加，但不能遮挡脸部识别链。

## 禁忌项

- 不要生成小黑、黑色豆状怪物、黑色剪影或替代角色。
- 不要删除或改变蓝碎发、白脸、黄鼻点和两枚黄腮红。
- 不要依赖耳机、蓝夹克、相机或笔记本完成识别。
- 不要把黄色参考背景带入正文配图；正文背景必须白色。
- 不要限制成只有蓝黄红，也不要为展示多色而无意义堆满彩虹。
- 不要让辅助色比品牌蓝更像主品牌色。
- 不要幼儿化、Q 版化、日漫化、真人化、3D 化或塑料化。
- 不要使用黑色主轮廓、巨大水光眼、写实肤色面部、渐变、重阴影和复杂背景。
- 不要生成光滑企业矢量、AI 海报光效、随机 Logo、水印或长段乱码。
- 不要让角色只站在角落；必须参与核心概念动作。
