# Bornforthis 个人 IP Skill 实战教程 HTML PPT

## 打开方式

直接双击 `index.html`，或在本目录启动本地服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 演示操作

- `→`、`↓`、`PageDown` 或空格：下一屏。
- `←`、`↑` 或 `PageUp`：上一屏。
- `Home` / `End`：首屏 / 末屏。
- 点击右侧圆点：跳转指定屏。
- `?`：打开快捷键帮助。
- 每个步骤下方都有紧凑的 Prompt 抽屉；可直接复制，也可展开阅读全文。

移动端采用纵向滚动和自适应重排，不隐藏内容。

## 内容与资产

- 共 22 屏，采用“完整 8 步方法 → Bornforthis 真实案例 → 小白复制工具包”的三段结构，全程只讲把原插图 Skill 的 IP 角色和画风替换成自己的。
- 方法篇完整覆盖 8 个节点：Fork 仓库、学习结构、给参考图、写 Prompt、试生成、批量生成、改写文件、推送；中英文之间统一留空格，每一步都配一张解释动作的 Bornforthis 插图和可直接复制的 Prompt。
- 案例篇使用用户实际对话、两张身份锚点、V1 → V3 返工、14 张压力测试、真实 Git commit 和 `demo/01.md` 正向实测作为证据。
- 复用本项目两张参考图、V1/V2/V3 总览、14 张 V3 压力测试和 `demo/01.md` 的 6 张文章实测图。
- 新增 8 张由 `$bornforthis-illustrations` 生成的独立步骤插图，保留在 `assets/`。
- `assets/REFERENCE-ANALYSIS.md`、`assets/SKILL-REPLACEMENT-CHECKLIST.md` 与 `assets/QA.md` 是真实项目证据副本。
