COPY KIT · 验收

完成标准不是“看起来挺像”

1遮住文字、衣服和配饰仍能认出 IP。
2不同场景中年龄、脸、发型和一词识别点稳定。
3配饰不固化；颜色规则能解释且不过度限制。
4新 Skill 独立安装，旧 IP 残留扫描通过。
5真实文章调用后仍能服务内容。
复制：最终 QA
对新 Skill 做最终验收。逐项核验：角色身份、年龄比例、一词识别点、背景、画风、品牌色职责、辅助色语义、构图、文字、服装与配饰纪律、旧 IP 残留、内部路径、示例数量、本地安装、Git 提交和真实文章实测。每项必须给出文件或图片证据；没有实际查看证据时不得宣称通过。最后列出“已通过 / 待修复 / 阻塞”。
